# 追星女防沉迷网站 💸

> 输入你这次追星准备花多少钱，看看这笔钱还能干嘛。

一个纯前端换算工具，把追星消费横向对比：购物、旅行、变美、运动、美食、情绪消费、生活升级。数据基于 2025-2026 年中国年轻女性真实消费场景。

---

## 使用方法

1. 打开网站
2. 输入你这次追星准备花多少钱
3. 点「看看值不值」
4. 冷静一下（或者更上头）

---

## 技术栈

纯 HTML / CSS / JavaScript，零依赖，单个文件即可运行。

## 部署

拖到 [Vercel](https://vercel.com) 或 [Netlify](https://netlify.com) 即可上线。

```bash
# 本地跑
python3 -m http.server 8080
# 打开 http://localhost:8080/fan-spend-compare.html
```
